Metodologia

O modelo é estimado separadamente para cada uma das 27 unidades federativas. Para cada estado, um LASSO é treinado nas 104 semanas mais recentes já consolidadas, usando como preditores os índices semanais do Google Trends para os termos gripe, sintomas gripe e tosse na própria semana. A estimativa final é a média entre esse LASSO e um método sazonal ingênuo: o valor observado de SRAG na mesma semana do ano anterior (52 semanas antes).

O agregado Brasil é a soma das 27 estimativas estaduais — não é um modelo treinado separadamente para o país. As faixas de 80% são conformais: usam os percentis 10 e 90 dos resíduos fora da amostra (out-of-fold) de cada modelo. A faixa do Brasil é calibrada a partir dos resíduos da soma das estimativas estaduais, e não da soma das faixas estaduais.

No mapa de nowcast, as estimativas são apresentadas em casos por 100 mil habitantes, usando a população residente do Censo Demográfico 2022 do IBGE. Os demais valores são contagens absolutas; o mapa de variação mostra percentuais. As métricas de desempenho histórico usam as mesmas previsões fora da amostra que calibram os modelos.

Este é um nowcast, não uma previsão: ele estima semanas que já ocorreram, mas cuja notificação ainda está incompleta por atraso no sistema de vigilância. Um caso só entra como "consolidado" depois de um número mínimo de dias desde o início dos sintomas; semanas mais recentes do que isso aparecem como provisórias no gráfico.

Atualização

Os índices do Google Trends são coletados diariamente, em lotes pequenos por estado, de segunda a sábado. Aos sábados, com os 27 estados disponíveis, o pipeline baixa os arquivos do SIVEP-Gripe, retreina os modelos e publica um novo pacote de dados. Uma atualização com falha nunca substitui os últimos dados válidos.

Limitações

Os índices do Google Trends são normalizados de 0 a 100 separadamente para cada estado e não devem ser comparados diretamente entre UFs. A amostragem do Trends pode variar levemente entre extrações. As estimativas são experimentais e não substituem os dados oficiais do Ministério da Saúde.

Fontes: SIVEP-Gripe / Ministério da Saúde, Google Trends e Censo Demográfico 2022 / IBGE.
