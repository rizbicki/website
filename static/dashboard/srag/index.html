Como interpretar

Este é um nowcast: ele estima a incidência de semanas que já ocorreram, mas cujas notificações ainda não estão consolidadas. Não é uma previsão de semanas futuras. Cada modelo estadual usa 104 semanas consolidadas e combina 50% de LASSO com 50% do número observado 52 semanas antes.

O agregado Brasil é a soma dos 27 nowcasts estaduais. Os índices do Google Trends são normalizados separadamente em cada UF e não devem ser comparados diretamente entre estados. As estimativas são experimentais e não substituem os dados oficiais do Ministério da Saúde.
